# 功能评估与工作量

原版为 LYOS 产品业务系统，机器人状态、动作、标定与私有 SDK 耦合；直接逐项通用化成本高。选择保留前端资产、独立实现最小 ROS2 后端。

| 模块 | 当前情况 | 后续工作 |
|---|---|---|
| robotapp | 独立 C++，状态机/IMU/电机健康 | 按真实 app 修订模拟场景 |
| 消息契约 | 自定义消息及标准消息快照分开 | 接入真实消息时验证兼容性 |
| Drogon 后端 | 配置订阅、JSON 缓存、HTTP/WS、失联恢复已验证 | 长时间运行与流控 |
| 导航 | 本地地图/点/路线及移动模拟已验证 | 前端适配 |
| React | 原布局/组件保留，目录迁移 | 新消息字段、WS 和导航接入 |
| 资源健康/日志 | 不纳入当前 Demo | 后续另行定范围 |
| Orin NX | 未部署 | 目标环境确认后单独验证 |

后续估算（单人有效工作日，非承诺工期）：前端适配 3–5 天；真实 app 接入 2–4 天；Orin NX 环境确认及部署验证 2–4 天；稳健性完善 2–3 天。涉及真实机器人消息或系统版本变化时需重新估算。

当前后端可作为本机联调基线，不等同于完整平台或生产交付。
