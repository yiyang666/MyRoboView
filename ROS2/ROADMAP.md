# 实施路线

1. 已实现：独立消息包、robotapp 三类发布、Drogon 配置订阅和 WebSocket、导航模拟。
2. 当前验收：x64 Ubuntu 24.04 / Jazzy，用户手动启动，检查状态变化、话题失联及恢复、导航模拟；测试后全部退出。
3. 已实现本轮前端适配：新状态字段与 WebSocket、电机健康卡片、2D 地图/目标点/路线操作、重连提示。导航按钮发布 IotCmdMsg，导航任务同时驱动后端模拟；3D 暂不加入。
4. 通用机器人接入：只运行 backend，替换配置话题与类型，验证目标 app 的 QoS、字段、时间戳与断连语义。
5. Orin NX：确认目标系统与 ROS 版本后再做 arm64 构建、部署及安装文档；没有实机测试不得标记完成。

本阶段不做资源健康、日志、真实导航执行反馈、产品业务动作和标定。
